ในชีวิตจริง รถวิ่งด้วยความเร็วสูง ไม่สามารถเปลี่ยนจากไฟเขียวเป็นไฟแดงทันทีได้ ระบบจึงมี Prepare State (ไฟเหลือง) เตือนให้รถชะลอความเร็วก่อน จากนั้นจึงเปลี่ยนเข้าสู่ Wait Stop State (ไฟแดงคู่ รถแดง + คนแดง) เพื่อให้กล้อง AI ตรวจจับจนแน่ใจว่ารถหยุดสนิทจริง ๆ แล้วจึงปล่อยคนเดินข้ามถนน (Go State)

1. Define State & 2. Describe State (การกำหนดและอธิบายสถานะ)

ชื่อ State ไฟสัญญาณรถ ไฟสัญญาณคนข้าม ไฟปุ่มกด (Push Button) คำอธิบายหน้าที่การทำงาน
Ready State GREEN (เขียว) RED (แดง) Inactive (สีฟ้า/ดับ) สถานะปกติ รถวิ่งผ่านได้ตลอดเวลา คนยังข้ามไม่ได้ ปุ่มกดพร้อมรับคำสั่ง
Prepare / Wait Stop State RED (แดง) RED (แดง) Active (สีแดง/ติด) [ตรงตามโจทย์] สัญญาณไฟแดงทั้งรถและคน (แดงคู่) เพื่อรอให้รถเบรกหยุดนิ่งสนิท กล้อง AI กำลังตรวจวัดความเร็ว
Go State RED (แดง) GREEN (เขียว) Active (สีแดง/ติด) กล้องส่งสัญญาณว่ารถหยุดแล้ว ปล่อยสัญญาณไฟเขียวให้คนเดินข้ามถนนได้อย่างปลอดภัย
Wait State GREEN (เขียว) RED (แดง) Active (สีแดง/ติด) สถานะ Cooldown ระบายรถหลังคนข้ามเสร็จ ป้องกันคนกดปุ่มซ้ำทันทีจนรถติดสะสม

3. Draw Transition (เส้นเชื่อมการเปลี่ยนสถานะ)

ไดอะแกรมแสดงเส้นเชื่อมระหว่าง State อย่างถูกต้อง มี Initial State ชี้เข้า Ready, Transition ขาลงและขากลับ, รวมถึง Self-Loop ของเหตุการณ์ push ในสถานะที่ไม่รับคำสั่งซ้ำ

4. Define Transition & 5. Define Guard Condition (การกำหนดเงื่อนไขและการทริกเกอร์)

From State (ต้นทาง) To State (ปลายทาง) Trigger / Event (เหตุการณ์) Guard Condition (เงื่อนไขความปลอดภัย) Action / Output (การตอบสนอง)
Ready Prepare push (คนกดปุ่ม) - ไฟปุ่มกดติดแดง, ไฟรถเปลี่ยนเป็นไฟแดง (หรือเหลืองใน 5-state)
Prepare Go stop (สัญญาณจากกล้อง AI) [car_stopped == true] (รถหยุดสนิทจริง) ไฟคนข้ามเปลี่ยนเป็น ไฟเขียว, เริ่มนับเวลาคนข้าม
Go Wait timer (หมดเวลาคนข้าม) [cross_time >= 15s] ไฟคนข้ามกลับเป็นไฟแดง, ไฟรถเปลี่ยนเป็น ไฟเขียว
Wait Ready timer (ครบเวลาระบายรถ) [cooldown_time >= 20s] ไฟปุ่มกดกลับเป็นสีฟ้า/พร้อมใช้งานสำหรับรอบถัดไป
Prepare / Go / Wait (Self Loop) push (กดซ้ำ) - เพิกเฉยคำสั่ง (Ignore) เพื่อรักษาจังหวะการทำงานให้ปลอดภัย
