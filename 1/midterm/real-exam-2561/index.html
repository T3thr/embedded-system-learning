ข้อ 1 (8 คะแนน)

การเขียนโปรแกรมควบคุม LED Logic Monitor กระพริบสลับ (8051 Assembly)

หน้า 7 ของกระดาษข้อสอบ
รูปถ่ายข้อสอบจริงหน้า 7: รูปที่ 1 การเชื่อมต่อ MCS-51 กับ LEDs (Logic Monitor)
โจทย์ที่ถอดจากรูปภาพกระดาษข้อสอบ

1. หากมีการเชื่อมต่อ MCS-51 กับ LEDs (Logic Monitor) เป็นดังรูปที่ 1 จงเขียนโปรแกรมแสดงผลเป็นการกระพริบสลับไปมาของ LED 0 และ LED 1 โดยมีเงื่อนไขดังนี้ (8 คะแนน)

  • เริ่มต้นให้ LED 0 ทำการกระพริบ 5 ครั้ง โดยให้ LED 1 ดับ
  • จากนั้นสลับให้ LED 1 ทำการกระพริบ 5 ครั้งแทน โดยให้ LED 0 ดับ
  • กลับมาเริ่มที่ LED 0 กระพริบใหม่แล้วแสดงผลวนไปไม่รู้จบ
การวิเคราะห์วงจรฮาร์ดแวร์และพฤติกรรมการทำงาน (Hardware Analysis)
  • การต่อวงจรพอร์ต: ขาพอร์ต P1.0 ต่อเข้ากับขั้ว Anode ของ LED 0 และขาพอร์ต P1.1 ต่อเข้ากับขั้ว Anode ของ LED 1 โดยมีขั้ว Cathode ต่อลงกราวด์ (GND) ผ่านตัวต้านทาน
  • ระดับลอจิกในการขับหลอด (Active-HIGH):
    • จ่ายลอจิก 1 (HIGH / +5V) → กระแสไหลผ่านไดโอด → LED สว่าง (ON)
    • จ่ายลอจิก 0 (LOW / 0V) → ไม่มีกระแสไหล → LED ดับ (OFF)
  • พฤติกรรมการวนลูป:
    • เฟสที่ 1: สั่ง P1.1 = 0 (LED1 ดับตลอด) แล้วสั่ง P1.0 ติด-ดับ สลับกันโดยหน่วงเวลา นับเป็น 1 ครั้ง ทำซ้ำจนครบ 5 ครั้ง (ใช้ Loop Counter R2 = 5)
    • เฟสที่ 2: สั่ง P1.0 = 0 (LED0 ดับตลอด) แล้วสั่ง P1.1 ติด-ดับ สลับกันโดยหน่วงเวลา นับเป็น 1 ครั้ง ทำซ้ำจนครบ 5 ครั้ง (ใช้ Loop Counter R2 = 5)
    • วนลูปหลัก: ใช้คำสั่ง SJMP วนกลับไปทำเฟส 1 ซ้ำอย่างไม่รู้จบ
ซอร์สโค้ดภาษาแอสเซมบลี 8051 ฉบับสมบูรณ์ (Full Assembly Solution)
8051 Assembly (.asm) 
; ===================================================================
; โปรแกรม: ควบคุม LED0 และ LED1 กระพริบสลับกันตัวละ 5 ครั้ง วนลูปไม่รู้จบ
; ฮาร์ดแวร์: Active HIGH บนพอร์ต P1.0 (LED0) และ P1.1 (LED1)
; ===================================================================

        ORG     0000H           ; Reset Vector
        LJMP    MAIN            ; กระโดดข้ามไปยังโปรแกรมหลัก

        ORG     0030H           ; เริ่มต้นพื้นที่โปรแกรมหลัก
MAIN:
        MOV     P1, #00H        ; ดับ LED ทุกดวงบนพอร์ต P1 ตอนเริ่มต้น

MAIN_LOOP:
; -------------------------------------------------------------------
; เฟสที่ 1: LED0 กระพริบ 5 ครั้ง (LED1 ดับสนิทตลอดเวลา)
; -------------------------------------------------------------------
        CLR     P1.1            ; ยืนยันให้ LED1 ดับ (P1.1 = 0)
        MOV     R2, #5          ; กำหนดตัวนับรอบการกระพริบ 5 ครั้ง
BLINK_LED0:
        SETB    P1.0            ; LED0 ติดสว่าง (P1.0 = 1)
        ACALL   DELAY           ; หน่วงเวลาขณะติด
        CLR     P1.0            ; LED0 ดับ (P1.0 = 0)
        ACALL   DELAY           ; หน่วงเวลาขณะดับ
        DJNZ    R2, BLINK_LED0  ; ลดค่า R2 และวนซ้ำจนครบ 5 รอบ

; -------------------------------------------------------------------
; เฟสที่ 2: LED1 กระพริบ 5 ครั้ง (LED0 ดับสนิทตลอดเวลา)
; -------------------------------------------------------------------
        CLR     P1.0            ; ยืนยันให้ LED0 ดับ (P1.0 = 0)
        MOV     R2, #5          ; กำหนดตัวนับรอบการกระพริบ 5 ครั้ง
BLINK_LED1:
        SETB    P1.1            ; LED1 ติดสว่าง (P1.1 = 1)
        ACALL   DELAY           ; หน่วงเวลาขณะติด
        CLR     P1.1            ; LED1 ดับ (P1.1 = 0)
        ACALL   DELAY           ; หน่วงเวลาขณะดับ
        DJNZ    R2, BLINK_LED1  ; ลดค่า R2 และวนซ้ำจนครบ 5 รอบ

        SJMP    MAIN_LOOP       ; วนกลับไปเริ่มเฟส 1 ใหม่อย่างไม่รู้จบ

; ===================================================================
; รูทีนย่อยหน่วงเวลา (Software Delay Subroutine)
; ===================================================================
DELAY:
        MOV     R7, #200
D1:     MOV     R6, #250
D2:     DJNZ    R6, D2          ; ลูปใน: 250 รอบ
        DJNZ    R7, D1          ; ลูปนอก: 200 รอบ
        RET                     ; กลับสู่โปรแกรมหลัก

        END                     ; สิ้นสุดโปรแกรม
ข้อ 2 (4 คะแนน)

การเข้าถึงหน่วยความจำ 8052 ในพื้นที่ต่างๆ (Memory Map & Addressing)

หน้า 8 ของกระดาษข้อสอบ
รูปถ่ายข้อสอบจริงหน้า 8: รูปที่ 2 แผนภาพหน่วยความจำไมโครคอนโทรลเลอร์เบอร์ 8052
รูปถ่ายข้อสอบจริงหน้า 8: คำถามข้อย่อย 2.1 – 2.3
โจทย์ที่ถอดจากรูปภาพกระดาษข้อสอบ

2. หากต้องการย้ายข้อมูลจากตำแหน่ง 80H ในพื้นที่หน่วยความจำดังรูปที่ 2 มาไว้ที่ Accumulator (A) จะต้องดำเนินการด้วยคำสั่งใด ตามลำดับ

  • 2.1. พื้นที่ของหน่วยความจำข้อมูลภายใน (หมายเลข 1) (1 คะแนน)
  • 2.2. พื้นที่ของรีจิสเตอร์ฟังก์ชันพิเศษ (หมายเลข 2) (1 คะแนน)
  • 2.3. พื้นที่ของหน่วยความจำข้อมูลภายนอก (หมายเลข 3) (2 คะแนน)
การวิเคราะห์สถาปัตยกรรมหน่วยความจำ 8052 (Architectural Analysis)

ในชิป 8052 มีหน่วยความจำ Data RAM ภายในขยายเป็น 256 Bytes ทำให้ช่วงแอดเดรส 80H - FFH มี 2 บล็อกซ้อนทับกัน (Overlapping Logical Spaces):

  • หมายเลข (1) Upper 128 Bytes RAM (80H - FFH): ต้องเข้าถึงด้วย Indirect Addressing ผ่าน Pointer (@R0 หรือ @R1) เท่านั้น
  • หมายเลข (2) Special Function Registers (SFRs 80H - FFH): ต้องเข้าถึงด้วย Direct Addressing เท่านั้น (เช่น MOV A, 80H)
  • หมายเลข (3) External Data Memory (0000H - FFFFH): ต้องเข้าถึงด้วยคำสั่ง MOVX ร่วมกับ 16-bit Pointer (DPTR) หรือ 8-bit Pointer (Ri)
เฉลยและวิธีทำอย่างละเอียด

ข้อย่อย 2.1: ย้ายข้อมูลจาก Internal RAM หมายเลข (1) ตำแหน่ง 80H มาไว้ที่ A

        MOV     R0, #80H        ; โหลดแอดเดรส 80H ใส่ Pointer R0
        MOV     A, @R0          ; ย้ายข้อมูลจากตำแหน่งที่ R0 ชี้มาไว้ใน A (Indirect Addressing)

ข้อย่อย 2.2: ย้ายข้อมูลจาก SFR หมายเลข (2) ตำแหน่ง 80H มาไว้ที่ A

        MOV     A, 80H          ; ย้ายข้อมูลจาก SFR แอดเดรส 80H (Port 0) มาไว้ใน A โดยตรง (Direct Addressing)

ข้อย่อย 2.3: ย้ายข้อมูลจาก External Data RAM หมายเลข (3) ตำแหน่ง 0080H มาไว้ที่ A

        MOV     DPTR, #0080H    ; กำหนดแอดเดรส 16 บิต 0080H ให้ Data Pointer
        MOVX    A, @DPTR        ; อ่านข้อมูลจาก External Data Memory มาไว้ใน A

จุดที่รุ่นพี่เขียนผิดในกระดาษข้อสอบ:

  • ในข้อ 2.2 รุ่นพี่เขียน MOV A, #80H ซึ่ง ผิดหลักการอย่างร้ายแรง เพราะเครื่องหมาย # หมายถึงเอาค่าคงที่ 80H ใส่ A ไม่ใช่การอ่านค่าจาก SFR แอดเดรส 80H (คำตอบที่ถูกคือ MOV A, 80H ไม่มีเครื่องหมาย #)
  • ในข้อ 2.3 รุ่นพี่เขียน MOVX @DPTR, #80H แล้วตามด้วย MOV A, @DPTR ซึ่ง ผิดไวยากรณ์ทั้งสองบรรทัด (คำตอบที่ถูกคือ MOV DPTR, #0080H แล้วตามด้วย MOVX A, @DPTR)
ข้อ 3 (4 คะแนน)

การประมวลผลคำสั่งทางคณิตศาสตร์และตรรกศาสตร์ (RLC, ANL, SWAP, MUL)

หน้า 9 ของกระดาษข้อสอบ
รูปถ่ายข้อสอบจริงหน้า 9: ข้อ 3, 4, 5
โจทย์ที่ถอดจากรูปภาพกระดาษข้อสอบ

3. สมมติว่า Accumulator (A) มีค่าเท่ากับ F5H รีจิสเตอร์ B มีค่าเท่ากับ 20H และแฟลกทด (CY) มีค่าเท่ากับ 0 หากถูกดำเนินการโดยคำสั่งต่อไปนี้ ผลลัพธ์ที่ถูกเก็บไว้ใน Accumulator A จะมีค่าเป็นเท่าไร (4 คะแนน)

  • 3.1. RLC A
  • 3.2. ANL A, #33H
  • 3.3. SWAP A
  • 3.4. MUL AB

(หมายเหตุ: ค่าของ A ในแต่ละข้อย่อยไม่มีความต่อเนื่องกัน เริ่มต้นจากสภาพเดิมทุกข้อ)

แสดงวิธีคิดและเฉลยคำตอบทีละข้อย่อย

สภาพเริ่มต้น: A = F5H = 1111 0101₂, B = 20H = 0010 0000₂ = 32₁₀, CY = 0

3.1 ข้อย่อย RLC A (Rotate Left through Carry):

  • หลักการ: หมุนบิตใน A ไปทางซ้าย 1 ตำแหน่ง บิต 7 ไปเก็บที่ CY บิตเดิมของ CY เข้ามาที่บิต 0 ของ A
  • การคำนวณ: บิต 7 ของ A คือ 1 → CY_ใหม่ = 1, บิต 0 รับ CY_เดิม = 0, บิตที่เหลือ 111 0101 เลื่อนซ้ายเป็น 1110 1010₂ = EAH
  • ผลลัพธ์: A = EAH (และ CY = 1)

3.2 ข้อย่อย ANL A, #33H (Bitwise AND):

    A   =  F5H  =  1 1 1 1   0 1 0 1
   #33H =  33H  =  0 0 1 1   0 0 1 1
   --------------------------------- (AND)
  ผลลัพธ์       =  0 0 1 1   0 0 0 1  =  31H

ผลลัพธ์: A = 31H

3.3 ข้อย่อย SWAP A (สลับ High/Low Nibbles):

  • หลักการ: สลับ 4 บิตบน (High Nibble) กับ 4 บิตล่าง (Low Nibble) ภายใน A
  • การคำนวณ: เดิม A = F5H (High = F, Low = 5) → หลังสลับ High กลายเป็น 5, Low กลายเป็น F
  • ผลลัพธ์: A = 5FH

3.4 ข้อย่อย MUL AB (คูณเลข 8 บิตใน A และ B):

  • หลักการ: นำ A × B ผลคูณขนาด 16 บิตจะเก็บ Low Byte ใน A และ High Byte ใน B (ถ้าผลคูณ > 255 แฟลก OV = 1)
  • การคำนวณ: 245 × 32 = 7840₁₀ = 1EA0H
  • แยกไบต์: High Byte = 1EH (เก็บใน B), Low Byte = A0H (เก็บใน A)
  • ผลลัพธ์ใน A: A = A0H (โดยใน B = 1EH, OV = 1, CY = 0)
ข้อ 4 (2 คะแนน)

การคำนวณคาบเวลารอบการทำงาน (Machine Cycle) จาก Crystal 18.4321 MHz

หน้า 9 ของกระดาษข้อสอบ
โจทย์ที่ถอดจากรูปภาพกระดาษข้อสอบ

4. หากบอร์ดไมโครคอนโทรลเลอร์ MCS-51 มีความถี่ Crystal เท่ากับ 18.4321 MHz ในหนึ่งรอบการทำงาน (Machine Cycle) จะใช้เวลาเท่าไร (แสดงวิธีทำโดยละเอียด) (2 คะแนน)

ทฤษฎีระบบสัญญาณนาฬิกา 8051 (Timing Analysis)
  • ในสถาปัตยกรรมมาตรฐาน 8051: 1 Machine Cycle ประกอบด้วย 6 States (S1 - S6)
  • แต่ละ State ประกอบด้วย 2 Oscillator Clock Pulses (P1, P2)
  • ดังนั้น: 1 Machine Cycle = 12 Oscillator Clock Pulses
  • สูตรความถี่และคาบเวลา:
    • f_machine = f_osc / 12
    • T_machine = 1 / f_machine = 12 / f_osc
แสดงวิธีทำอย่างละเอียด

กำหนดให้: ความถี่ของ Crystal Oscillator f_osc = 18.4321 MHz = 18.4321 × 10⁶ Hz

  1. คำนวณความถี่รอบการทำงานของเครื่อง (f_machine): 
    f_machine = 18.4321 × 10⁶ Hz / 12 ≈ 1.53600833 × 10⁶ Hz ≈ 1.536 MHz
  2. คำนวณเวลาที่ใช้ในหนึ่งรอบการทำงาน (T_machine): 
    T_machine = 12 / (18.4321 × 10⁶ Hz)
          ≈ 0.65103813 × 10⁻⁶ วินาที
          ≈ 0.651038 µs (หรือประมาณ 651.04 ns)

คำตอบ: ในหนึ่งรอบการทำงาน (Machine Cycle) จะใช้เวลา 0.651038 µs (หรือ 651.04 ns)

ข้อ 5 (10 คะแนน)

เปรียบเทียบความแตกต่างระหว่าง Microprocessor และ Microcontroller

หน้า 10 ของกระดาษข้อสอบ
โจทย์ที่ถอดจากรูปภาพกระดาษข้อสอบ

5. ความแตกต่างระหว่างไมโครโปรเซสเซอร์กับไมโครคอนโทรลเลอร์ คืออะไร อธิบายโดยละเอียด (10 คะแนน)

ตารางเปรียบเทียบเชิงวิศวกรรม 8 มิติ (Comprehensive 8-Dimension Comparison)
มิติการเปรียบเทียบ ไมโครโปรเซสเซอร์ (Microprocessor - MPU) ไมโครคอนโทรลเลอร์ (Microcontroller - MCU)
1. นิยามและโครงสร้างหลัก บรรจุเฉพาะหน่วยประมวลผลกลาง (CPU Only) ได้แก่ ALU, Control Unit, และ General Registers บนชิปเดี่ยว ไม่มีหน่วยความจำหรือพอร์ต I/O ภายในตัว บรรจุระบบคอมพิวเตอร์ครบวงจรในชิปเดี่ยว (Single-Chip Microcomputer) ประกอบด้วย CPU, RAM, ROM/Flash, I/O Ports, Timers, และ Interrupts เบ็ดเสร็จในตัว
2. การเชื่อมต่อระบบบัส ต้องต่อเชื่อม System Bus ภายนอก (Address, Data, Control Bus) เข้ากับชิป RAM, ROM, I/O Controller ทำให้วงจร PCB ซับซ้อนและมีขนาดใหญ่ สัญญาณบัสส่วนใหญ่เชื่อมต่อ ภายในชิป (Internal Bus) ขาภายนอกทำหน้าที่เป็นพอร์ต I/O สำหรับต่อกับเซนเซอร์หรืออุปกรณ์ภายนอกโดยตรง
3. วัตถุประสงค์การใช้งาน ออกแบบมาสำหรับงานประมวลผลทั่วไป (General-Purpose Computing) ที่ต้องการความยืดหยุ่นสูง รันโปรแกรมที่หลากหลายและซับซ้อน (เช่น OS) ออกแบบมาสำหรับงานควบคุมเฉพาะทาง (Dedicated / Specific Control Application) มักรันโปรแกรมชุดเดียวตลอดอายุการใช้งาน (Firmware)
4. ความยืดหยุ่น (Flexibility) สูงมาก สามารถปรับเปลี่ยน เพิ่ม/ลด ขนาดของ RAM, หน่วยความจำถาวร (SSD/HDD), และการ์ดเชื่อมต่อ I/O ต่างๆ ได้ตามต้องการ คงที่ ทรัพยากรภายใน (ขนาด RAM, Flash, จำนวนขา I/O, Timers) ถูกกำหนดตายตัวมาจากโรงงานตามเบอร์ของชิป
5. การใช้พลังงานและขนาด ใช้พลังงานไฟฟ้าสูง (หลักหลายวัตต์ถึงร้อยวัตต์) เกิดความร้อนสูง ต้องมีระบบระบายความร้อน (Heatsink/Fan) ขนาดวงจรบอร์ดใหญ่ กินพลังงานต่ำมาก (หลักมิลลิวัตต์หรือไมโครวัตต์) รองรับโหมดประหยัดพลังงาน (Sleep/Power-down) ทำงานด้วยแบตเตอรี่ได้ยาวนาน
6. ความเร็วและประสิทธิภาพ ทำงานที่ความถี่สัญญาณนาฬิกาสูงมาก (หลายร้อย MHz ถึงระดับหลาย GHz), สถาปัตยกรรมแบบ Multi-core 32-bit / 64-bit, มีระบบ Cache หลายระดับ ทำงานที่ความถี่สัญญาณนาฬิกาต่ำกว่า (หลักสิบ kHz ถึงระดับร้อยกว่า MHz), โครงสร้างมักเป็น 8-bit หรือ 32-bit เน้นความแน่นอนของเวลา (Deterministic Timing)
7. ต้นทุนระบบโดยรวม ต้นทุนรวมของระบบสูงมาก เนื่องจากต้องซื้อชิปประมวลผล, ชิปหน่วยความจำ, ชิปควบคุม I/O, ชิปจัดการพลังงาน และบอร์ด PCB หลายเลเยอร์ ต้นทุนต่อชิ้นต่ำมาก (หลักสิบบาทถึงร้อยกว่าบาท) ช่วยลดจำนวนอุปกรณ์บนบอร์ด (BOM Cost) ได้อย่างมหาศาล เหมาะแก่การผลิตเชิงอุตสาหกรรม
8. ตัวอย่างการใช้งานจริง Personal Computer (PC), Laptops, Servers, Cloud Data Centers, High-end Smart Devices (เช่น Intel Core i9, AMD Ryzen, Apple M-series) เครื่องใช้ไฟฟ้าในบ้าน (ไมโครเวฟ, แอร์, เครื่องซักผ้า), ยานยนต์ (ECU, ระบบเบรก ABS), อุปกรณ์การแพทย์, IoT Devices (เช่น MCS-51, PIC, AVR, STM32, ESP32)

ข้อย่อย 6.1: ขนาดของโปรแกรม (1 คะแนน)

  • บรรทัดที่ 2 (MOV A, #00H): รหัส 74 00 = 2 ไบต์ (0030H, 0031H)
  • บรรทัดที่ 3 (START: MOV A, P1): รหัส E5 90 = 2 ไบต์ (0032H, 0033H)
  • บรรทัดที่ 4 (MOV P0, A): รหัส F5 80 = 2 ไบต์ (0034H, 0035H)
  • บรรทัดที่ 5 (SJMP START): รหัส 80 FA = 2 ไบต์ (0036H, 0037H)
  • (คำสั่ง ORG และ END เป็นคำสั่งควบคุม Assembler Directive ไม่ใช้พื้นที่หน่วยความจำ)
  • คำตอบ: ขนาดรวมของโปรแกรม = 2 + 2 + 2 + 2 = 8 ไบต์ (Bytes)

ข้อย่อย 6.2: ข้อมูลในช่องว่าง ( * ) มีค่าเป็นเท่าไร อธิบาย (2 คะแนน)

  • คำตอบ: 80 (หรือ 80H)
  • คำอธิบาย: คำสั่ง MOV P0, A มีรูปแบบคือ MOV direct, A (Opcode F5H ตามด้วย Direct Address) ซึ่งรีจิสเตอร์พอร์ต 0 (P0) เป็น Special Function Register (SFR) ที่ประจำอยู่ที่ตำแหน่งแอดเดรส 80H ทำให้แปลงเป็น Machine Code ได้เป็น F5 80

ข้อย่อย 6.3: ข้อมูลในช่องว่าง ( ** ) มีค่าเป็นเท่าไร อธิบาย (3 คะแนน)

  • คำตอบ: FA (หรือ FAH)
  • คำอธิบายและวิธีคิด:
    • คำสั่ง SJMP START อยู่ที่แอดเดรส 0036H มีขนาด 2 ไบต์
    • ค่าของ Program Counter (PC) ของคำสั่งถัดไปหลังจากอ่านคำสั่งนี้คือ 0036H + 2 = 0038H
    • แอดเดรสเป้าหมายปลายทาง (START) คือ 0032H
    • Relative Offset = Target Address - PC of Next Instruction = 0032H - 0038H = -6₁₀
    • แปลง -6₁₀ เป็น Two's Complement 8 บิต: +6 = 0000 0110₂ → กลับบิตเป็น 1111 1001₂ → บวก 1 ได้ 1111 1010₂ = FAH
ข้อสังเกตเปรียบเทียบกับลายมือทดของรุ่นพี่:

ในกระดาษข้อสอบ รุ่นพี่ทดไว้ว่า FB (กระโดด -5) ซึ่งเป็นความเข้าใจผิดที่นำแอดเดรสปลายทางไปลบกับ 0037H แทนที่จะใช้ค่า PC ของคำสั่งถัดไป (0038H) ตามสเปกสถาปัตยกรรม 8051 ค่าที่ถูกต้องตามหลักวิศวกรรมคือ FA

ข้อย่อย 6.4: จงเขียนไฟล์คำสั่งภาษาเครื่องของโปรแกรมนี้ (TEST.HEX) แสดงวิธีคิด (4 คะแนน)

โครงสร้างเรคคอร์ด Intel HEX: : [LL: Byte Count] [AAAA: Address] [TT: Type] [DD...: Data] [CC: Checksum]

สูตร Checksum: Checksum = Two's Complement of (Sum of all bytes mod 256) = 100H - (Sum mod 100H)

  1. บรรทัดที่ 1 (Data Record):
    • LL = 08 (8 ไบต์), AAAA = 0030, TT = 00 (Data Record)
    • Data = 7400E590F58080FA
    • Sum = 08H + 00H + 30H + 00H + 74H + 00H + E5H + 90H + F5H + 80H + 80H + FAH = 510H
    • Checksum = 100H - 10H = F0H
    • ผลลัพธ์บรรทัดที่ 1: :080030007400E590F58080FAF0
  2. บรรทัดที่ 2 (End of File Record):
    • LL = 00, AAAA = 0000, TT = 01 (EOF Record)
    • Sum = 00H + 00H + 00H + 01H = 01H
    • Checksum = 100H - 01H = FFH
    • ผลลัพธ์บรรทัดที่ 2: :00000001FF
