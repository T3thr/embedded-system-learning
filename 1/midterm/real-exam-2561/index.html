ข้อ 1 (8 คะแนน)

เขียนโปรแกรม Assembly ควบคุมวงจร LED Logic Monitor

หน้า 7 ของกระดาษข้อสอบ
รูปถ่ายข้อสอบจริงหน้า 7: วงจร LED Logic Monitor
โค้ดภาษาแอสเซมบลีฉบับสมบูรณ์ (พร้อมฟังก์ชันหน่วงเวลา 1 วินาที)
8051 Assembly (.asm) 
        ORG     0000H           ; Reset Vector
        LJMP    MAIN

        ORG     0030H           ; Main Program Address
MAIN:   MOV     P1, #0FFH       ; Configure P1 as Input (P1.0 = Switch)

LOOP:   JB      P1.0, CHECK_HIGH ; If P1.0 == 1 -> JUMP to CHECK_HIGH

        ; CASE 0: P1.0 is LOW (0V) -> Turn ON LED0 (P0.0=0), Turn OFF LED1 (P0.1=1)
        CLR     P0.0            ; Active LOW -> LED0 ON
        SETB    P0.1            ; LED1 OFF
        ACALL   DELAY_1S        ; Delay 1 second
        SJMP    LOOP

CHECK_HIGH:
        ; CASE 1: P1.0 is HIGH (+5V) -> Turn OFF LED0 (P0.0=1), Turn ON LED1 (P0.1=0)
        SETB    P0.0            ; LED0 OFF
        CLR     P0.1            ; Active LOW -> LED1 ON
        ACALL   DELAY_1S        ; Delay 1 second
        SJMP    LOOP

; ==========================================================
; Delay Subroutine: Approx 1.0 Second Delay (at 12MHz Crystal)
; ==========================================================
DELAY_1S:
        MOV     R7, #10
D_L1:   MOV     R6, #200
D_L2:   MOV     R5, #250
D_L3:   DJNZ    R5, D_L3
        DJNZ    R6, D_L2
        DJNZ    R7, D_L1
        RET

        END
ข้อ 2 (4 คะแนน)

8052 Memory Map (Internal RAM, SFR, External RAM)

หน้า 8 ของกระดาษข้อสอบ
รูปถ่ายข้อสอบจริงหน้า 8: ไดอะแกรม 8052 Memory Map
เฉลยคำตอบข้อย่อย 2.1 – 2.3

2.1 วิธีการเข้าถึง Upper 128 Bytes RAM vs SFR ในช่วงแอดเดรส 80H - FFH:

  • Upper 128 Bytes RAM (ภายใน 8052): เข้าถึงได้ด้วย Indirect Addressing เท่านั้น เช่น MOV R0, #80H ตามด้วย MOV A, @R0
  • Special Function Registers (SFRs): เข้าถึงได้ด้วย Direct Addressing เท่านั้น เช่น MOV A, 80H หรือ MOV A, P0

2.2 วิธีการเข้าถึง External Data Memory (RAM ภายนอก 64 KB):

  • ต้องใช้คำสั่ง `MOVX` ร่วมกับ Data Pointer (`DPTR`) หรือ `Ri` เช่น MOV DPTR, #8000H แล้วสั่ง MOVX A, @DPTR
ข้อ 6 (10 คะแนน)

การแปลง Cross-Assembler Listing และสร้าง Intel HEX File

หน้า 11 ของกระดาษข้อสอบ
รูปถ่ายข้อสอบจริงหน้า 11: Table 1 Cross-Assembler Listing
ตัวอย่างบรรทัด Intel HEX Record ที่ถูกต้อง
Intel HEX Format 
:080030007580AA7800E604F6FA17
:00000001FF

โครงสร้างของ Intel HEX Record:

  • : = Start Code
  • 08 = Byte Count (8 ไบต์)
  • 0030 = Address เริ่มต้นที่ `0030H`
  • 00 = Record Type (00 = Data Record)
  • 7580AA7800E604F6 = Data Bytes (รหัสภาษาเครื่อง)
  • 17 = Checksum (Two's complement ของผลรวมไบต์ทั้งหมดในบรรทัด)
