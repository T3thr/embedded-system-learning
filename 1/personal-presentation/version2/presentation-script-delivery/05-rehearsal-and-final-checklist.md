## รอบซ้อมที่ 1: เข้าใจเนื้อหา

ปิดบทพูด แล้วอธิบายภาพรวมด้วยคำของตนเองให้ครบห้าคำถามต่อไปนี้

1. เหตุการณ์จาก peripheral เปลี่ยนเป็น request ของ CPU ได้อย่างไร
2. ทำไม flag ที่เป็น 1 จึงไม่ได้แปลว่า CPU เข้า ISR แล้วเสมอ
3. vector มีหน้าที่อะไร และทำไม address จึงขึ้นกับ architecture
4. ระหว่างเข้า ISR ต้องรักษา context อะไรบ้าง
5. RET ต่างจาก RETI อย่างไรใน 8051

ถ้าตอบได้เฉพาะคำจำกัดความแต่เชื่อมลำดับไม่ได้ ให้กลับไปอ่าน `02-teaching-notes-before-speaking.md` หัวข้อ causal chain

## รอบซ้อมที่ 2: พูดตามสไลด์

พูดโดยดูเฉพาะหัวข้อบนสไลด์ ห้ามอ่านบทพูดเต็ม ให้ใช้บทพูดเต็มเป็นเอกสารตรวจสอบหลังซ้อม รอบนี้ควรฟังเป็นธรรมชาติและไม่เกิดอาการอ่านรายงาน

### เกณฑ์ผ่าน

- พูดได้ครบว่า interrupt เป็นการเปลี่ยน control flow ชั่วคราว ไม่ใช่การลบโปรแกรมหลัก
- แยก polling, flag, request, ISR และ vector ได้
- เมื่อพูด 8051 จะระบุว่าเป็น 8051/MCS-51 ไม่ใช้คำว่า MCU ทุกชนิดเหมือนกัน
- เมื่อพูด AVR หรือ ARM จะระบุว่าเป็นตัวอย่างเปรียบเทียบ
- ไม่กล่าวว่า RETI ตั้ง EA เป็น 1 เสมอโดยไม่มีเงื่อนไข
- จบภายใน 2:00–2:59 นาที

## รอบซ้อมที่ 3: ตรวจการออกเสียงคำสำคัญ

| คำ | แนวการออกเสียง/การขยายครั้งแรก |
|---|---|
| MCU | “เอ็ม-ซี-ยู หรือ microcontroller unit” |
| ISR | “ไอ-เอส-อาร์ หรือ interrupt service routine” |
| SFR | “เอส-เอฟ-อาร์ หรือ special function register” |
| PC | “พี-ซี หรือ program counter” |
| SP | “เอส-พี หรือ stack pointer” |
| EA | “อี-เอ หรือ global/external enable bit ของ 8051” |
| IP | “ไอ-พี หรือ interrupt priority register ของ 8051” |
| RETI | “รีเทิร์น-ฟรอม-อินเทอร์รัพท์” หรือเรียก “คำสั่ง RETI” แล้วอธิบายเต็มครั้งแรก |
| latency | “เวลาแฝงของการตอบสนอง” |
| jitter | “ความแปรผันของเวลาแฝง” |

## รอบซ้อมที่ 4: จำลองคำถามอาจารย์

ตอบไม่เกิน 20 วินาทีต่อคำถาม และเริ่มด้วยการระบุขอบเขต architecture ก่อนตอบ

- “ทำไมไม่ polling”
- “flag กับ request เหมือนกันไหม”
- “8051 save อะไรตอนเข้า interrupt”
- “ทำไมใช้ RETI”
- “EA กับ global interrupt enable ของ AVR เหมือนกันไหม”
- “interrupt ทำให้เป็น real-time หรือไม่”
- “ถ้า flag ไม่เคลียร์จะเกิดอะไรขึ้น”
- “vector table กับ ISR เหมือนกันไหม”

คำตอบเต็มอยู่ใน `04-technical-glossary-and-qa.md`

## วิธีดูเป็นมนุษย์และไม่เหมือนท่องบท

ให้จำ causal chain แทนการจำประโยค: “เกิดเหตุการณ์ → เกิด request/flag → ผ่านการอนุญาต → เข้า vector → ISR รักษา context และบริการ → clear/acknowledge → RETI → โปรแกรมหลักทำต่อ” เมื่อจำโครงนี้ได้ ให้พูดด้วยถ้อยคำของตนเองโดยรักษาคำศัพท์ architecture-specific ให้ถูกต้อง
