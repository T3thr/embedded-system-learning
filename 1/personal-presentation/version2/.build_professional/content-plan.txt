SLIDE 2 — ความหมายและความเป็นมา
Title: Interrupt คือการถ่ายโอนการควบคุมตามเหตุการณ์ [1][2]
Definition: คำขอที่เกิดแบบอะซิงโครนัสจะทำให้หน่วยประมวลผลเข้าสู่ ISR ภายใต้เงื่อนไขที่กำหนด ก่อนกลับไปดำเนินโปรแกรมเดิม
Properties: Event-driven; State-preserving; Vectored; Priority-aware.

SLIDE 3 — กลไกและการทำงาน
Title: การตอบสนองแบ่งเป็น 3 ระยะต่อเนื่อง [1][2][3][4]
Phase 1 Request: Event/flag -> Pending; retain request until eligible when architecture supports it.
Phase 2 Entry: enable/mask/priority arbitration -> save architectural state -> vector fetch.
Phase 3 Service & Return: execute ISR/acknowledge source -> architectural return -> restore/resume.

SLIDE 4 — กลไกและการทำงาน
Title: ความถูกต้องขึ้นกับสถานะ แหล่งคำขอ และเวลาตอบสนอง [2][3][4]
Qualification: request must pass enable, mask, and priority rules.
State integrity: save/restore scope is architecture-defined; software must preserve additional state it modifies.
Bounded service: ISR acknowledges the source and finishes essential work promptly to control latency and jitter.
