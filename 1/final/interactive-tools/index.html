สรุปสูตร Timer Load (Course Formula)
  • Machine cycle: T = 12 / Fosc µs (Fosc หน่วย MHz) — ที่ 12 MHz ได้ T = 1 µs
  • Mode 1 (16-bit): Load = FFFFH − N + 1 แล้วแยกเป็น TH (ไบต์สูง) / TL (ไบต์ต่ำ)
  • Mode 0 (13-bit): Load = 1FFFH − N + 1 โดย TH ใช้ 8 บิต และ TL ใช้เฉพาะบิต 4–0 (simplified 8051 convention: TH = Load[12:5], TL = Load[4:0])
  • Mode 2 (8-bit auto-reload): TH = TL = (256 − N) mod 256 — เหมาะกับ baud generator เพราะ reload อัตโนมัติ
  • ข้อควรระวัง: ถ้า N > max counts ของ mode จะวนกลับ (overflow) ต้องเลือก mode ใหญ่ขึ้นหรือแบ่ง delay เป็นหลายรอบ

Baud Rate Calculator — Timer 1 สร้าง Baud ให้ UART Mode 1/3

8051 Serial UART

สูตรมาตรฐาน: Baud = (2^SMOD / 32) × (Fosc / 12) / (256 − TH1) และค่าโหลดย้อนกลับ TH1 = 256 − (2^SMOD × Fosc) / (384 × Baud) โดย Fosc ต้องเป็นหน่วย Hz ในสูตร TH1

ทำไมต้อง 11.0592 MHz?
  • 11.0592 MHz ÷ 12 = 921,600 Hz ลงตัวกับตัวหารมาตรฐานของ UART (9600, 4800, 2400, 19200 เมื่อ SMOD=1) ทำให้ % Error = 0
  • 12 MHz ÷ 12 = 1,000,000 Hz ไม่ลงตัวกับ 384 × 9600 ทำให้ TH1 ไม่เป็นจำนวนเต็ม — baud เพี้ยน ~8.5%
  • งาน Timer ทั่วไปชอบ 12 MHz (T = 1 µs คิดง่าย) แต่งาน Serial UART ควรเลือก 11.0592 MHz
  • เมื่อใช้ Timer 1 สร้าง baud ต้องตั้ง Timer 1 Mode 2 (8-bit auto-reload) เพื่อให้ reload TH1 อัตโนมัติทุก overflow

สรุปหน้าที่รีจิสเตอร์ควบคุม
  • TMOD (89H): เลือก mode ของ Timer 1 (นิเบิลสูง) และ Timer 0 (นิเบิลต่ำ) — แต่ละนิเบิลคือ GATE | C/T | M1 | M0
  • TCON (88H): ธง overflow (TF1/TF0), บิตสตาร์ท (TR1/TR0), และ external interrupt (IE1/IT1/IE0/IT0)
  • SCON (98H): Serial mode (SM0/SM1), multi-processor (SM2), receive enable (REN), และธง TI/RI
  • IE (A8H): เปิด/ปิด interrupt รายตัว + EA (global enable)
  • IP (B8H): ลำดับความสำคัญ (priority) ของแต่ละ interrupt
  • PCON (87H): SMOD (double baud), GF1/GF0, PD (Power Down), IDL (Idle)

ข้อ 24: Delay 20 µs ด้วย Timer (โจทย์ย่อ)

จงเขียนโปรแกรมหน่วงเวลา 20 µs โดยใช้ Timer 0 Mode 1 ที่ Fosc = 12 MHz พร้อมคำนวณค่าที่โหลดเข้า TH0/TL0

แนวคิดจากโน้ตรุ่นพี่
  • ที่ 12 MHz → 1 machine cycle = 1 µs ดังนั้น 20 µs ต้องการ 20 counts (14H)
  • ใช้ Timer 0 Mode 1 (16-bit): โหลดค่าตั้งต้น = FFFFH − N + 1
  • ต้อง CLR TF0 ก่อนเริ่ม และ SETB TR0 เพื่อสตาร์ท แล้วรอจน TF0 = 1
เฉลยสมบูรณ์ — คำนวณทีละขั้น
  1. Machine cycle: T = 12 / 12 MHz = 1 µs
  2. Counts: N = 20 µs / 1 µs = 20 = 14H
  3. Max check: Mode 1 ได้ 65,536 counts — 20 อยู่ในช่วง
  4. ค่าโหลด: FFFFH − 14H + 1 = FFECH
  5. แยกไบต์: TH0 = FFH, TL0 = ECH
8051 Assembly — Delay 20 µs (Timer 0 Mode 1) 
        ORG     0000H
        LJMP    MAIN

        ORG     0030H
MAIN:
        MOV     TMOD, #01H    ; Timer 0 Mode 1 (16-bit)
        MOV     TH0, #0FFH   ; Load = FFECH
        MOV     TL0, #0ECH   ; TH0:TL0 = FFEC H
        CLR     TF0            ; เคลียร์ overflow flag
        SETB    TR0            ; เริ่ม Timer 0
WAIT:
        JNB     TF0, WAIT    ; รอจนครบ 20 counts
        CLR     TR0            ; หยุด Timer
        CLR     TF0
HERE:
        SJMP    HERE           ; จบโปรแกรม (วนอยู่กับที่)
        END

คำตอบ: TH0 = FFH, TL0 = ECH (ค่ารวม FFECH) — ลองกดชิป “ข้อ 24” ในเครื่อง Timer Calculator ด้านบนเพื่อดูซ้ำแบบสด

ข้อ 25: Square Wave 1 kHz บน TxD (โจทย์ย่อ)

จงสร้าง square wave ความถี่ 1 kHz ที่ขารับส่งข้อมูล TxD โดยใช้ Timer 1 ที่ Fosc = 12 MHz จงหาค่าโหลดและเขียนโปรแกรม

(โจทย์เต็ม: คาบเวลาของสัญญาณ 1 kHz = 1000 µs → ครึ่งคาบ High/Low = 500 µs ต่อ half-period)

แนวคิดจากโน้ตรุ่นพี่
  • Square wave 1 kHz → คาบ = 1 ms = 1000 µs → สลับ TxD ทุก 500 µs
  • ที่ 12 MHz, T = 1 µs → ต้องการ 500 counts (1F4H) ต่อ half-period
  • ใช้ Timer 1 Mode 1: Load = FFFFH − 1F4H + 1 = FE0CH
  • ใน ISR / ลูป: โหลดซ้ำ TH1:TL1 = FE0CH แล้ว CPL P3.1 (TxD) ทุกครั้งที่ overflow
เฉลยสมบูรณ์ — คำนวณทีละขั้น
  1. คาบเวลา: f = 1 kHz → T_wave = 1 / 1000 = 1 ms = 1000 µs
  2. Half-period: 1000 µs / 2 = 500 µs (High 500 µs + Low 500 µs)
  3. Machine cycle: T = 12 / 12 MHz = 1 µs
  4. Counts: N = 500 µs / 1 µs = 500 = 1F4H
  5. ค่าโหลด Mode 1: FFFFH − 1F4H + 1 = FE0CH
  6. แยกไบต์: TH1 = FEH, TL1 = 0CH
8051 Assembly — 1 kHz Square Wave on TxD (Timer 1 Mode 1) 
        ORG     0000H
        LJMP    MAIN

        ORG     0030H
MAIN:
        MOV     TMOD, #10H    ; Timer 1 Mode 1 (16-bit)
        MOV     TH1, #0FEH   ; Load = FE0CH → half-period 500 µs
        MOV     TL1, #0CH
        SETB    TR1            ; เริ่ม Timer 1
LOOP:
        JNB     TF1, LOOP    ; รอครบ 500 µs
        CLR     TF1            ; เคลียร์ overflow flag
        MOV     TH1, #0FEH   ; โหลดค่าตั้งต้นใหม่ (Mode 1 ไม่ auto-reload)
        MOV     TL1, #0CH
        CPL     P3.1           ; สลับสถานะ TxD → 1 kHz square wave
        SJMP    LOOP
        END

คำตอบ: TH1 = FEH, TL1 = 0CH (ค่ารวม FE0CH) ได้ square wave 1 kHz ที่ TxD (P3.1)
