เสาหลัก 1
โจทย์จากกระดาษข้อสอบ

T0 และ T1 ประกอบด้วยอะไรบ้าง

โน้ตรุ่นพี่ / กับดักข้อสอบ
  • Timer 0 และ Timer 1 แต่ละตัวเป็น 16-bit register ที่แยกเป็น 2 ไบต์: TLx (Low) + THx (High)
  • ควบคุมผ่าน TMOD (mode/C-T/GATE) และ TCON (TRx/TFx)
  • เวลา Timer ล้น (overflow) จะตั้งแฟลก TFx และสามารถเรียก Interrupt ได้
  • T0 มี modes 0,1,2,3 ส่วน T1 มี modes 0,1,2 (mode 3 ของ T1 หยุดทำงาน)
เฉลยฉบับวิศวกรรม

Timer 0 (T0) และ Timer 1 (T1) ของ 8051 แต่ละตัวประกอบด้วย:

  • ตัวนับ 16 บิต แบ่งเป็น 2 รีจิสเตอร์ 8 บิต ได้แก่ TL0/TH0 สำหรับ T0 และ TL1/TH1 สำหรับ T1
  • TMOD (Timer Mode Register) กำหนด Mode (M1,M0), เลือกนับ Clock ภายใน/ภายนอก (C/T̄) และ GATE
  • TCON (Timer Control Register) เก็บ TR0/TR1 (เริ่ม-หยุด) และ TF0/TF1 (แฟลกล้น)

Load นับเวลายังไง

โน้ตรุ่นพี่ / กับดักข้อสอบ
  • Timer นับขึ้นจากค่าที่ load ไปจนถึง FFFFH แล้ว overflow → TF=1
  • ดังนั้นค่าที่ load ต้องเป็น ค่าตั้งต้นที่ชดเชย ไม่ใช่จำนวน counts ตรงๆ
  • สูตรหลัก (Mode 1): Initial = FFFFH − N + 1 เมื่อ N = จำนวน counts ที่ต้องการ
  • โหลด: MOV TH0, #High / MOV TL0, #Low แล้ว SETB TR0
เฉลยฉบับวิศวกรรม

หลักการ load ค่าเพื่อสร้าง delay:

  1. เลือก Mode (มักใช้ Mode 1 = 16-bit)
  2. คำนวณจำนวน counts N = Delay / (12/Fosc) → ที่ Fosc=12 MHz หนึ่ง count = 1 µs
  3. คำนวณค่าเริ่มต้น: Initial = FFFFH − N + 1
  4. แยกไบต์: THx = Initial[15:8], TLx = Initial[7:0]
  5. เขียน TMOD แล้ว SETB TRx เริ่มนับ รอจน TFx = 1
Load calculation 
N = 20 counts
Initial = FFFFH - 20 + 1 = FFFFH - 13H + 1 = FFFECH?  (decimal step)
Step: FFFFH - 14H + 1 = FFECH
TH0 = FFH,  TL0 = ECH

ตัวอย่าง load ค่า 20 µs (Mode 1, Fosc=12 MHz):

8051 Assembly (.asm) 
        ORG 0000H
        MOV TMOD, #00000001B ; T0 Mode 1
        MOV TL0,  #0ECH ; Low byte  of FFECH
        MOV TH0,  #0FFH ; High byte of FFECH
        SETB TR0 ; start counting up to FFFFH
HERE: JNB TF0, HERE ; wait overflow (20 counts)
        CLR TR0
        CLR TF0
        RET
        END

  • ตัวอย่างโจทย์: Value = 7 → Count = FFF9H
  • Mode 1: ค่าที่โหลด = ค่าที่เหลือก่อนถึง FFFFH
  • อย่าลืมเขียน TMOD ให้เป็น Timer/Counter mode ที่ต้องการก่อนเริ่ม TRx
เฉลยฉบับวิศวกรรม

สูตรคำนวณค่า load (Mode 1 — จากกระดาษข้อสอบ):

Formula + worked example 
Count (load value) = FFFFH - Value + 1

ตัวอย่างจากข้อสอบ: Value = 7
  Count = FFFFH - 7 + 1
        = FFFFH - 6
        = FFFAH?   <-- คำนวณแบบ modular 16-bit:

วิธีที่ถูกตามกระดาษ (นับถอยหลังจาก FFFF ไป Value counts):
  Count = FFFFH - Value + 1
        = FFFFH - 0007H + 1
        = FFF8H + 1
        = FFF9H

ดังนั้นโหลด TH0=FFH, TL0=F9H เมื่อ Value=7

โค้ดตัวอย่าง: ตั้ง Timer 0 Mode 1 ให้ครบ N counts แล้วหยุด (ใช้ N = 7 ตามตัวอย่างข้อสอบ)

8051 Assembly (.asm) 
; ===================================================================
; สูตร Count = FFFFH - Value + 1   (Mode 1)
; ตัวอย่าง Value = 7  ->  Count = FFF9H
; ===================================================================
        ORG 0000H
        LJMP MAIN

        ORG 0030H
MAIN:
        MOV TMOD, #00000001B ; Timer 0 Mode 1 (16-bit)
        MOV TL0,  #0F9H ; load FFF9H
        MOV TH0,  #0FFH
        SETB TR0 ; start timer
WAIT:
        JNB TF0, WAIT ; wait until 7 counts overflow
        CLR TR0 ; stop timer
        CLR TF0 ; clear overflow flag
        SETB P2.0 ; indicate done
HERE:
        SJMP HERE

        END

คำตอบ: clock ภายใน (internal oscillator/12 หรือ machine cycle clock) เมื่อ C/T̄=0

clock แบบไหนเป็น counter

โน้ตรุ่นพี่ / กับดักข้อสอบ
  • Counter ใช้ pulse จากขาภายนอก T0 (P3.4) หรือ T1 (P3.5)
  • นับทุกขอบ 1→0 (falling edge) ของสัญญาณภายนอก
  • ต้องตั้งบิต C/T̄ = 1
  • ความถี่สัญญาณภายนอกต้อง ≤ Fosc/24

โหมด Counter นับเหตุการณ์จาก สัญญาณภายนอก ที่ขา:

  • Timer 0 รับ pulse ที่ขา T0 (P3.4)
  • Timer 1 รับ pulse ที่ขา T1 (P3.5)
  • นับเมื่อเกิด ขอบ 1→0 (High-to-Low)
  • ตั้งค่า: C/T̄ = 1 ใน TMOD เพื่อเลือก Counter mode

คำตอบ: clock/pulse ภายนอกที่ขา T0 หรือ T1 เมื่อ C/T̄=1

เสาหลัก 1

Timer และ counter ทำงานอย่างไร จงวาดแผนผังการทำงาน

โน้ตรุ่นพี่ / กับดักข้อสอบ
  • Timer = นับ clock ภายใน, Counter = นับ pulse ขา T0/T1
  • ผ่าน MUX ที่เลือกด้วย C/T̄ แล้วเข้า THx/TLx
  • GATE=1 ต้องมี INTx=1 ด้วยจึงจะนับ (เปิดด้วยฮาร์ดแวร์)
  • ครบ 16-bit → TFx=1 / กระตุ้น Interrupt
เฉลยฉบับวิศวกรรม

แผนผังการทำงาน (Block Diagram แบบข้อความ):

Timer/Counter block diagram 
                    Fosc/12 (internal) ----+
                                           |
   T0/T1 pin (external pulse) ----> [C/T MUX] --> [GATE AND INTx] --> [THx:TLx +1]
                                           |            ^
                                      C/T=0 Timer       | TRx=1
                                      C/T=1 Counter     |
                                                        |
                                              Overflow --> TFx = 1 --> Interrupt?

TMOD:  [GATE | C/T | M1 | M0]  x 2 (T1 | T0)
TCON:  [TF1 | TR1 | TF0 | TR0 | IE1 | IT1 | IE0 | IT0]

หลักการทำงาน:

  1. เลือกแหล่งนับ: C/T̄=0 รับ clock ภายใน (Timer), C/T̄=1 รับขอบขา T0/T1 (Counter)
  2. เงื่อนไขเปิดนับ: TRx=1 และ (GATE=0 หรือ INTx=1)
  3. การนับ: ตัวนับบวก 1 ทุก tick เมื่อถึง FFFFH → overflow
  4. ผลลัพธ์: ตั้ง TFx=1 แล้วเริ่มนับจาก 0000H ใหม่ (Mode 1) หรือ reload THx (Mode 2)

  • RxD (P3.0) = ขารับข้อมูลอนุกรม (Receive Data)
  • SBUF = บัฟเฟอร์ส่ง/รับ — เขียนแล้วส่ง, อ่านแล้วได้ข้อมูลที่รับ

  • RxD (P3.0) — Serial Receive Data: รับข้อมูลเข้าชิป (RXD)

; FSM 2 สถานะ: READY / GO
; Input : P2.0 = push button (active-low)
; Output: P1.1 = LED Ready, P1.0 = LED Go
; State : R0 = 0 (READY), R0 = 1 (GO)

        LJMP MAIN

DEBOUNCE:

; FSM 4 สถานะ: READY / PREPARE / GO / WAIT
; Input : P2.1 = start signal from ESP32 (active-low)
; Output: P1.0=Ready  P1.1=Prepare  P1.2=Go  P1.3=Wait
; State : R0 = 0,1,2,3

        LJMP MAIN

        ORG 0030H

        MOV R0, #0 ; state = READY
        MOV P1, #00H

        CJNE A, #0, T_NOT0
        LJMP S_READY
T_NOT0: CJNE A, #1, T_NOT1
        LJMP S_PREPARE
T_NOT1: CJNE A, #2, T_NOT2
        LJMP S_GO
T_NOT2: LJMP S_WAIT

; ---------------- READY (R0=0) ----------------
S_READY:
        MOV P1, #00000001B ; P1.0
        JB P2.1, FSM_LOOP ; ESP32 not requesting -> stay
        ACALL DEBOUNCE
        MOV R0, #1 ; -> PREPARE
        LJMP FSM_LOOP

; ---------------- PREPARE (R0=1) ----------------
S_PREPARE:
        MOV P1, #00000010B ; P1.1
        MOV R5, #20
        ACALL DELAY_UNITS
        MOV R0, #2 ; -> GO
        LJMP FSM_LOOP

; ---------------- GO (R0=2) ----------------
S_GO:

        MOV R5, #30
        ACALL DELAY_UNITS
        MOV R0, #3 ; -> WAIT
        LJMP FSM_LOOP

; ---------------- WAIT (R0=3) ----------------
S_WAIT:
        MOV P1, #00001000B ; P1.3
        MOV R5, #15
        ACALL DELAY_UNITS
        MOV R0, #0 ; -> READY
        LJMP FSM_LOOP

; ===================================================================

DB1: MOV R6, #250
DB2: DJNZ R6, DB2
        DJNZ R7, DB1
        RET

DELAY_UNITS:
DU1: ACALL DELAY_UNIT
        DJNZ R5, DU1
        RET

DELAY_UNIT:
        MOV R7, #20
DU_A: MOV R6, #250
DU_B: DJNZ R6, DU_B
        DJNZ R7, DU_A
        RET

        END

8051 Assembly (.asm) 
; ===================================================================
; FSM Sliding Door: OPEN / WARNING / OPENING / CLOSING
; Inputs : P2.0 limit OPEN (0=at end), P2.1 limit CLOSE (0=at end)
;          P2.2 object detect (0=object present)
; Outputs: P1.0 LED Open, P1.1 LED Warning
;          P1.2 motor OPEN, P1.3 motor CLOSE
; State  : R0 = 0 Open, 1 Warning, 2 Opening, 3 Closing
; ===================================================================
        ORG 0000H
        LJMP MAIN

        ORG 0030H
MAIN:
        MOV R0, #2 ; power-on: start OPENING
        MOV P1, #00H

FSM_LOOP:
        MOV A, R0
        CJNE A, #0, N0
        LJMP ST_OPEN
N0: CJNE A, #1, N1
        LJMP ST_WARNING
N1: CJNE A, #2, N2
        LJMP ST_OPENING
N2: LJMP ST_CLOSING

; ---------------- OPEN (R0=0) ----------------
ST_OPEN:
        MOV P1, #00000001B ; LED Open, motors off
        MOV R5, #40 ; dwell time at open
OP_WAIT:
        ACALL DELAY_UNIT
        ; object while open: stay open (reset dwell)
        JNB P2.2, OP_OBJ
        DJNZ R5, OP_WAIT
        MOV R0, #1 ; timeout -> WARNING
        LJMP FSM_LOOP
OP_OBJ: MOV R5, #40 ; reload dwell
        SJMP OP_WAIT

; ---------------- WARNING (R0=1) ----------------
ST_WARNING:
        MOV R5, #10
WN_BLINK:
        SETB P1.1 ; warning LED on
        ACALL DELAY_UNIT
        CLR P1.1 ; warning LED off
        ACALL DELAY_UNIT
        DJNZ R5, WN_BLINK
        MOV R0, #3 ; -> CLOSING
        LJMP FSM_LOOP

; ---------------- OPENING (R0=2) ----------------
ST_OPENING:
        MOV P1, #00000100B ; motor OPEN
OP_RUN:
        JB P2.2, OP_NOOBJ ; no object
        ; object during opening: stop motor briefly, retry
        MOV P1, #00H
        ACALL DELAY_UNIT
        MOV P1, #00000100B
OP_NOOBJ:
        JNB P2.0, OP_ARRIVED ; limit open reached (0)
        SJMP OP_RUN
OP_ARRIVED:
        MOV R0, #0 ; -> OPEN
        LJMP FSM_LOOP

; ---------------- CLOSING (R0=3) ----------------
ST_CLOSING:
        MOV P1, #00001000B ; motor CLOSE
CL_RUN:
        JNB P2.2, CL_OBJECT ; object detected -> reopen
        JNB P2.1, CL_ARRIVED ; limit close reached
        SJMP CL_RUN
CL_OBJECT:
        MOV R0, #2 ; -> OPENING (safety)
        LJMP FSM_LOOP
CL_ARRIVED:
        MOV P1, #00H ; stop, fully closed
        MOV R0, #2 ; go wait at open next cycle (exam simplification)
        ; For exam: sit in OPEN after close-complete via OPENING/OPEN
        MOV R0, #0
        LJMP FSM_LOOP

; ===================================================================
DELAY_UNIT:
        MOV R7, #20
DU_A: MOV R6, #250
DU_B: DJNZ R6, DU_B
        DJNZ R7, DU_A
        RET

        END

4. โค้ด 8051 Assembly ฉบับข้อสอบ (Exam-Length Skeleton ~85 บรรทัด)

8051 Assembly (.asm) — ครบถ้วน, รันได้จริงบน EdSim51, ความยาวพอดีเขียนในกระดาษสอบ 
; ===================================================================
; SLIDING_DOOR_EXAM_SKELETON.asm — Group 1 Final Exam Answer (Q56)
; Target: 8051 @ 12 MHz, 12T (1 machine cycle = 1 us)
; Port: P1 Actuators/LEDs, P2 Sensors/Buttons (P2 latch = FFH)
; ===================================================================
        ORG     0000H
        LJMP    MAIN

        ORG     0030H
MAIN:
        MOV     P2, #0FFH           ; กำหนด P2 เป็นอินพุตทั้งพอร์ต
        SETB    P1.2                ; ตัดแรงขับมอเตอร์ทันที (RUN_N = 1)
        MOV     P1, #0ECH           ; เริ่มต้นในสถานะ CLOSED (ไฟแดงติด)
        CLR     20H.0               ; 20H.0 คือแฟล็ก SAFETY_SEEN

; ---------- STATE 0: CLOSED ----------
S_CLOSED:
        MOV     P1, #0ECH           ; มอเตอร์หยุด, ไฟแดงติด
WAIT_OPEN:
        JNB     P2.0, DO_OPEN       ; ตรวจปุ่มภายใน (PB_IN กด = 0)
        JNB     P2.1, DO_OPEN       ; ตรวจปุ่มภายนอก (PB_OUT กด = 0)
        SJMP    WAIT_OPEN
DO_OPEN:
        LCALL   DELAY_20MS          ; กรองสัญญาณกระเพื่อม 20 ms
        JNB     P2.0, S_OPENING
        JNB     P2.1, S_OPENING
        SJMP    WAIT_OPEN

; ---------- STATE 1: OPENING ----------
S_OPENING:
        SETB    P1.2                ; Interlock: ตัด Enable ก่อนตั้งทิศ CW
        MOV     P1, #0D9H           ; ขับหมุน CW (IN1=1, IN2=0, ไฟเขียวติด)
WAIT_LO:
        JNB     P2.3, S_OPEN_HOLD   ; ถึงลิมิตสวิตช์เปิดสุด (LO = 0)
        SJMP    WAIT_LO

; ---------- STATE 2: OPEN_HOLD ----------
S_OPEN_HOLD:
        SETB    P1.2                ; มอเตอร์หยุด
        MOV     P1, #0DCH           ; ไฟเขียวติดค้าง
WAIT_CLOSE:
        JNB     P2.5, CHECK_CLOSE   ; มีการกด PB_CLOSE
        SJMP    WAIT_CLOSE
CHECK_CLOSE:
        LCALL   DELAY_20MS          ; กรองปุ่ม 20 ms
        JB      P2.5, WAIT_CLOSE
        JNB     P2.2, WAIT_CLOSE    ; ลำแสงขาด (0) -> ไม่อนุญาตให้ปิด
        SJMP    S_CLOSING

; ---------- STATE 3: CLOSING ----------
S_CLOSING:
        SETB    P1.2                ; Interlock: ตัด Enable ก่อนตั้งทิศ CCW
        MOV     P1, #0EAH           ; ขับหมุน CCW (IN1=0, IN2=1, ไฟแดงติด)
CLOSE_LOOP:
        JNB     P2.2, OBSTACLE_HIT  ; สิ่งกีดขวางตัดลำแสง (P2.2=0) -> ลำดับสูงสุด!
        JNB     P2.0, MANUAL_REOPEN ; คนกดปุ่มเปิดซ้ำ
        JNB     P2.1, MANUAL_REOPEN
        JNB     P2.4, S_CLOSED      ; ถึงลิมิตปิดสุด (LC = 0)
        SJMP    CLOSE_LOOP

OBSTACLE_HIT:
        SETB    20H.0               ; จดจำเหตุการณ์: แฟล็ก SAFETY_SEEN = 1
        SJMP    DO_REV_WAIT
MANUAL_REOPEN:
        CLR     20H.0               ; คนกดเปิดเอง: แฟล็ก SAFETY_SEEN = 0
DO_REV_WAIT:
        SETB    P1.2                ; ตัดแรงขับมอเตอร์ทันที (Safe cut-off)
        MOV     P1, #0FCH           ; ปล่อยไหล (Coast), ไฟดับทุกดวง
        SJMP    S_REV_WAIT

; ---------- STATE 4: REV_WAIT (พักเพลา ≥ 200 ms) ----------
S_REV_WAIT:
        MOV     R6, #10             ; วนลูปหน่วง 10 x 20 ms = 200 ms
COAST_LOOP:
        LCALL   DELAY_20MS
        DJNZ    R6, COAST_LOOP
        SJMP    S_REOPENING

; ---------- STATE 5: REOPENING ----------
S_REOPENING:
        SETB    P1.2                ; ตัด Enable ก่อนสลับทิศ
        MOV     P1, #0D9H           ; ขับหมุน CW เปิดกลับ
WAIT_REOPEN_LO:
        JNB     P2.3, REOPEN_DONE   ; ถึงลิมิตเปิด LO
        SJMP    WAIT_REOPEN_LO
REOPEN_DONE:
        JB      20H.0, S_SAFETY_HOLD ; หากเปิดกลับเพราะสิ่งกีดขวาง -> SAFETY_HOLD
        SJMP    S_OPEN_HOLD         ; หากเปิดกลับเพราะคนกดปุ่ม -> OPEN_HOLD

; ---------- STATE 6: SAFETY_HOLD ----------
S_SAFETY_HOLD:
        SETB    P1.2                ; มอเตอร์หยุด
        MOV     P1, #0BCH           ; ไฟส้มติดค้าง (ORANGE_N = 0)
WAIT_SAFE_REL:
        JB      P2.5, WAIT_SAFE_PRESS ; ต้องเห็นการปล่อยปุ่ม PB_CLOSE ก่อน
        SJMP    WAIT_SAFE_REL
WAIT_SAFE_PRESS:
        JNB     P2.5, DO_SAFE_CLOSE   ; คนกดปุ่มปิดครั้งใหม่หลังตรวจช่องทาง
        SJMP    WAIT_SAFE_PRESS
DO_SAFE_CLOSE:
        LCALL   DELAY_20MS          ; กรองปุ่ม
        JB      P2.5, WAIT_SAFE_PRESS
        JNB     P2.2, WAIT_SAFE_PRESS ; ทางผ่านต้องว่าง (BEAM_DET = 1)
        CLR     20H.0
        SJMP    S_CLOSING

; ---------- SUBROUTINE: DELAY_20MS ----------
; 12.000 MHz, 12T -> 1 machine cycle = 1 us
; Timer 0 Mode 1 (16-bit): 65536 - 20000 = 45536 = B1E0H
DELAY_20MS:
        MOV     TMOD, #01H          ; Timer 0 โหมด 1 (16 บิต)
        CLR     TR0
        MOV     TH0, #0B1H          ; โหลดไบต์สูง
        MOV     TL0, #0E0H          ; โหลดไบต์ต่ำ
        CLR     TF0
        SETB    TR0
WAIT_TF:
        JNB     TF0, WAIT_TF        ; รอ Timer 0 ล้นครบ 20 ms
        CLR     TR0
        CLR     TF0
        RET

        END
