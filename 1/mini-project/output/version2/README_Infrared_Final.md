## ข้อมูลที่ต้องเข้าใจก่อนนำเสนอ

ค่า P1 ที่คำนวณตามตำแหน่งบิตจริงเป็น EC, D9, DC, EA, FC, D9, BC ตามลำดับเจ็ดสถานะ ค่าเหล่านี้ตรงกันในแผนภาพ ตาราง และตัวอย่างโค้ด

ผล 21 จาก 21 กรณีมาจากแบบจำลอง Python ก้าวเวลาครั้งละ 1 ms ยังไม่ใช่ผล EdSim51 หรือผลวัดฮาร์ดแวร์จริง ตัวอย่างแอสเซมบลีแสดงเฉพาะส่วนควบคุมที่เกี่ยวข้อง ยังไม่ใช่เฟิร์มแวร์ครบชุด

ภาพบ้านและกลไกเป็นภาพจำลองแนวคิด ภาพชิ้นส่วนใช้บอกตำแหน่งอุปกรณ์ ผังขยายสายควบคุมหลักและต้องใช้วงจรขั้นต่ำ AT89S52 ประกอบด้วยตามเอกสารวิศวกรรม

## การแก้ไขไฟล์

ไฟล์ PowerPoint ใช้ข้อความ ตาราง ลูกศร และเส้นวงจรที่แก้ไขได้ ภาพอุปกรณ์เป็นรูปภาพ ฟอนต์ที่ใช้คือ Prompt, Sarabun และ JetBrains Mono ควรติดตั้งฟอนต์เหล่านี้บนเครื่องที่นำเสนอเพื่อคงรูปแบบ ตัวไฟล์ไม่ได้ฝังฟอนต์

สคริปต์อยู่ใน `infrared_final_source/` และรูปประกอบอยู่ใน `infrared_final_assets/` สร้างด้วย JavaScript และ artifact-tool ส่วน Python ใช้ตรวจแบบจำลอง FSM

- `build_deck.mjs`: สร้างสไลด์
- `visual_blocks.mjs`: ส่วนผัง FSM และวงจรที่ใช้ในสคริปต์สร้าง
- `formal_notes.json`: บทพูดภาษาไทย
- `render.mjs`: ส่งออก PNG จาก PPTX
- `test_fsm_model.py`: รันทดสอบ 21 กรณี

สคริปต์อ้างพาธ runtime บนเครื่องนี้ หากย้ายเครื่องต้องปรับพาธ runtime และฟอนต์ก่อนสร้างไฟล์ใหม่
