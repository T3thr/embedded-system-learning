# Sliding Door Safety Control RFID Version 2

## ไฟล์ส่งมอบ

- `Sliding_Door_Safety_Control_RFID_v2.pptx`: งานนำเสนอ 15 หน้า มีบทพูดภาษาไทยทุกหน้า
- `rfid_preview/`: ภาพ PNG ของสไลด์ทุกหน้า
- `RFID_v2_Scenario.png`: ภาพเปรียบเทียบปัญหาและแนวทาง RFID อัตราส่วน 16:9
- `RFID_v2_FSM.png`: แผนภาพ 7 สถานะ
- `RFID_v2_State_Table.csv`: ตารางสถานะเพลาและเอาต์พุต P1
- `RFID_v2_Speaker_Notes.md`: บทพูดครบทุกหน้า
- `RFID_v2_Design_Notes.md`: เงื่อนไขควบคุม รายละเอียดวงจร และแหล่งข้อมูล
- `rfid_source/`: โค้ดสร้างสไลด์ แบบจำลอง FSM กรณีทดสอบ และตัวอย่างแอสเซมบลี
- `rfid_assets/`: ภาพที่ใช้สร้างงาน

## โครงสร้าง 15 หน้า

1. ชื่อโครงงานและผู้จัดทำ
2. ปัญหาการหนีบและแนวทาง RFID
3. ตำแหน่งอุปกรณ์และทิศทางกลไก
4. คนเป็นผู้สั่งเปิดและปิดทุกครั้ง
5. อินเทอร์เฟซ RFID ที่เสนอ
6. วงจรขับมอเตอร์และการตัดแรงขับ
7. การจัดสรรพอร์ต AT89S52
8. FSM การทำงานปกติ 7 สถานะ
9. ตารางเอาต์พุตประจำสถานะ
10. เหตุการณ์และเงื่อนไขเปลี่ยนสถานะ
11. เวลาควบคุมและการหยุดฉุกเฉิน
12. การรับคำสั่งปิดใหม่ใน RFID_HOLD
13. ตัวอย่างแอสเซมบลีขณะกำลังปิด
14. ผลตรวจลอจิกและแผนทดสอบจริง
15. ขอบเขตและสิ่งที่ต้องยืนยัน

## สร้างไฟล์ใหม่จากโค้ด

บนเครื่องนี้ใช้คำสั่ง `python3 rfid_source/build_presentation.py` จากโฟลเดอร์นี้ ตัวสคริปต์ Python เรียก Artifact Tool ผ่าน JavaScript เพื่อรักษาข้อความ ตาราง และ FSM ให้แก้ไขใน PowerPoint ได้ โค้ดหลักอยู่ใน `rfid_source/build_deck.mjs` ไม่ใช้ python-pptx

ค่าเริ่มต้นสร้างชื่อ `Sliding_Door_Safety_Control_RFID_v2_rebuilt.pptx` โดยไม่เขียนทับไฟล์ที่มีอยู่ ใช้ `--output` เพื่อกำหนดชื่ออื่น เครื่องอื่นต้องปรับพาธ runtime และเครื่องมือในสคริปต์ก่อน

ภาพจำลองสร้างด้วย built-in ImageGen และเก็บภาพผลลัพธ์ไว้แล้ว ไม่ต้องสร้างภาพใหม่เมื่อแก้ข้อความ คำสั่งสร้างภาพอยู่ใน `rfid_source/image_prompts.md` ภาพเป็นภาพอธิบายแนวคิด ไม่ใช่ภาพต้นแบบของกลุ่ม

## การตรวจและข้อจำกัด

แบบจำลอง Python ผ่าน 21 กรณี เป็นผลตรวจลอจิกอ้างอิงเท่านั้น ไม่ใช่ผล EdSim51 หรือผลวัดฮาร์ดแวร์ ตัวอย่างแอสเซมบลียังไม่ใช่เฟิร์มแวร์ครบชุด

ยังไม่เลือกรุ่น Reader และ Tag จึงระบุเป็นอินเทอร์เฟซที่เสนอ ไม่อ้างระยะอ่าน แรงดันเครื่องอ่าน หรือความสามารถตรวจแท็กที่ยังไม่ได้ทดสอบ ระบบไม่ปิดเองตามเวลา และ RFID_HOLD ต้องรอการกดปิดใหม่หลังปล่อยปุ่ม โดยต้องไม่พบแท็ก

ต้นฉบับที่ลงท้าย `_final.pdf` และ `_final.pptx` ใช้เพื่ออ้างอิงและไม่ได้แก้ไข
