# ระบบประตูเลื่อนอัตโนมัติ ฉบับนำเสนอ Version 2

ไฟล์นำเสนอ: `Sliding_Door_Safety_Control_Version_2_Final.pptx` จำนวน 20 สไลด์

## เนื้อหา

1. ชื่อโครงงานและผู้จัดทำ
2. ปัญหาประตูเดิมเทียบกับแนวทางติดตั้งลำแสงสองระดับ
3. FSM พร้อมภาพแสดงตำแหน่งประตู
4. ผังการต่อวงจร โดยวาง L293D ตรงกลาง
5. แรงดันลอจิก 5 V และภาคมอเตอร์กับเซนเซอร์ 12 V
6. เวลารอแต่ละช่วงและเหตุผล
7. ตารางค่าพอร์ต
8. การเริ่มระบบ
9. ซับรูทีน Delay
10–16. โค้ดแยกตามสถานะ CLOSED, OPENING, HOLD, CLOSING, REV_WAIT, REOPEN และ FAULT
17. ความแตกต่างของเฟิร์มแวร์สองฉบับ
18. ผลทดสอบฉบับขยาย 36 เคส
19. ผลทดสอบฉบับสอน 20 เคส
20. สรุปและการทดสอบฮาร์ดแวร์ขั้นต่อไป

## เฟิร์มแวร์และผลทดสอบ

- `firmware/SLIDING_DOOR_CLASSROOM.asm` เป็นฉบับสอนที่ใช้ CALL Delay และเป็นที่มาของโค้ดบนสไลด์ 8–16 ผลทดสอบอยู่ใน `TEST_RESULTS_CLASSROOM.md` ผ่าน 20 เคส
- `firmware/SLIDING_DOOR.asm` เป็นฉบับขยายที่ใช้ Timer 0 interrupt และอ่านสัญญาณระหว่างรอ ผลทดสอบอยู่ใน `TEST_RESULTS.md` ผ่าน 36 เคส

สำเนาไฟล์ข้างต้นมาจากโฟลเดอร์ firmware ของโครงงานโดยไม่เปลี่ยนแปลง ผลทดสอบเป็นรายงานเดิมวันที่ 17 กันยายน 2026 ไม่ใช่การรันใหม่ในงานจัดสไลด์นี้

สไลด์โค้ดแสดงส่วนสำคัญของแต่ละสถานะเพื่อให้อ่านง่าย บางหน้าละคำสั่งบันทึก R0 หรือส่วนตั้งเอาต์พุตที่อธิบายไว้ด้านซ้าย รายละเอียดบล็อกเต็มอยู่ในบันทึกผู้บรรยาย ให้ใช้ไฟล์ `.asm` เต็มเมื่อต้องการประกอบและรันบน EdSim51

รูปประตูเป็นภาพอธิบายหลักการ ไม่ใช่แบบติดตั้งตามมาตราส่วน การติดตั้งจริงต้องวางลำแสงเยื้องจากระนาบบานเพื่อไม่ให้บานบังลำแสงเอง การตัดแรงขับคือ coast ไม่ได้หมายถึงหยุดการเคลื่อนที่ทางกลทันที ต้องวัดเวลาหยุด ระยะหยุด กระแสและความร้อนของชุดสาธิต

## แหล่งข้อมูล

ใช้ `PROPOSED_SOLUTION_DESIGN.md`, เอกสารใน `assignment`, ซอร์สใน `firmware`, สคริปต์เดิมใน `.build` และรายงานใน `.codex-finalizer` ของ mini-project เป็นแหล่งอ้างอิง โดยใช้คำขอ Version 2 เป็นเกณฑ์ในการจัดเนื้อหาใหม่ รายงาน 36 เคสและ 20 เคสแสดงแยกกันอย่างชัดเจน

ภาพตรวจงานแต่ละหน้าอยู่ใน `preview` ส่วนสคริปต์ประกอบสไลด์และรายงานตรวจโครงสร้างเก็บใน `.build`
