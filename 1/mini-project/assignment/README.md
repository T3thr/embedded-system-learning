# เอกสารประกอบ Mini-Project ระบบสมองกลฝังตัว 8051 (Home Automatic Sliding Door)

ไดเรกทอรีนี้ใช้สำหรับจัดเก็บเอกสารการวิเคราะห์ข้อกำหนดโครงงาน Mini-Project ภาพสไลด์จากเอกสารคำสอน และแนวทางการดำเนินงาน

## สารบัญเอกสาร

  - `13_sliding_door_components.png`: อุปกรณ์ฮาร์ดแวร์พื้นฐานของระบบประตูเลื่อน
